# RentalCar

RentalCar — вебзастосунок для пошуку та оренди автомобілів. Користувач може переглядати каталог, фільтрувати доступні автомобілі, відкривати сторінку з детальною інформацією та надсилати заявку на оренду.

Проєкт створено на Next.js з App Router, TypeScript і React. Дані отримуються із зовнішнього REST API, а серверний prefetch і синхронізація клієнтського кешу реалізовані за допомогою TanStack Query.

## Основні функції

- головна сторінка з переходом до каталогу;
- каталог автомобілів із фільтрацією за маркою, ціною та пробігом;
- поступове завантаження наступних сторінок каталогу;
- окрема сторінка `/catalog/[carId]` з фотографією та повною інформацією про автомобіль;
- серверне завантаження даних і гідратація клієнтського кешу;
- динамічні metadata для сторінок автомобілів;
- форма заявки на оренду, створена з Formik і Yup;
- повідомлення про успішне або невдале надсилання заявки через React Toastify;
- обробка станів завантаження, помилок API та відсутніх сторінок;
- адаптивний інтерфейс для різних розмірів екрана.

## Технології

- Next.js 16;
- React 19;
- TypeScript;
- TanStack Query;
- Axios;
- Formik і Yup;

## Встановлення

Для запуску потрібні Node.js версії 20.9 або новішої та npm.

1. Клонуйте репозиторій і перейдіть до директорії проєкту:

   ```bash
   git clone <repository-url>
   cd test-task
   ```

2. Встановіть залежності:

   ```bash
   npm install
   ```

3. Створіть файл `.env.local` у корені проєкту та вкажіть адресу API:

   ```env
   NEXT_PUBLIC_BASE_URL=https://example.com/api
   ```

   API має підтримувати отримання каталогу й окремого автомобіля, отримання параметрів фільтрації та створення заявки на оренду.

## Використання

Запустіть локальний сервер розробки:

```bash
npm run dev
```

Після запуску відкрийте [http://localhost:3000](http://localhost:3000) у браузері.

Основні маршрути:

- `/` — головна сторінка;
- `/catalog` — каталог і фільтри;
- `/catalog/[carId]` — детальна інформація та форма оренди автомобіля.

Для перевірки коду виконайте:

```bash
npm run lint
```

Для production-збірки та запуску:

```bash
npm run build
npm start
```
